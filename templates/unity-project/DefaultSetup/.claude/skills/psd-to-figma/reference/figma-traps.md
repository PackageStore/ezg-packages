# Figma traps

Every Plugin API, MCP and PSD-import trap this pipeline has already paid for,
once. **Symptom** is what you see, **cause** is why, **rule** is what to do
instead. An evidence cell that quotes a concrete node, screen, stem, style or
font from one import ends with the word *example* in parentheses — those tagged
cells are the only project-specific strings the skill is permitted to carry, and
the project-agnostic grep skips them. Read this before writing any `use_figma`
build or grouping code.

| id | symptom | cause | rule | evidence |
|---|---|---|---|---|
| P-1 | A grouping pass shifts every leaf on-canvas by its new container's origin. | `appendChild` keeps the child's local `x,y`; the parent's origin is added to world position. | Capture each child's `absoluteTransform` before reparenting, then set local `x/y = worldTx − parentTx` after; re-extract to confirm. | "appendChild does NOT preserve world position (keeps child local coords) → first grouping pass offset every leaf by its container's position; fixed by capturing absoluteTransform and re-setting local x/y after reparent, verified 0.00px" |
| P-2 | `resize()` on a child inside an instance is silently ignored; `x/y` assignment throws. | Instance children are immutable except fills, characters, name, visible and variant props; only the instance box resizes. | When per-instance art differs in size or position, make a variant, not an overlay. Everything is editable inside the master. | A yellow price plate could not be reused because `Btn_Price`'s child is MIN/MIN and cannot resize to the needed width, so a flat plate was built instead (example) |
| P-3 | Page-scoped reads return the wrong page under concurrent callers; a second `setCurrentPageAsync` throws. | `figma.currentPage` is shared, resettable state and `setCurrentPageAsync` may run at most once per script. | Address pages by id and fan multi-page work into parallel calls, one page each. | Contracts trap 7: "currentPage resets between calls, and setCurrentPageAsync may be called at most once per script" |
| P-4 | Stray frames litter the canvas after an upload. | `upload_assets` drops one placement frame per asset on the current page. | Record the placement-frame ids the upload returns and delete by id, printing each removal before deleting. | "Delete the placement frames upload_assets dropped: one use_figma call removing every node on the current page whose name matches, printing what was deleted first" |
| P-5 | `componentPropertyDefinitions` throws "Component set has existing errors". | Two variants share the same property value, putting the set into an error state. | Give every variant a unique `Type=` value before reading its properties or placing an instance. | A set with 34 unique variant options read cleanly (`defsErr=null`); duplicate values are what trip the error state |
| P-6 | An instance emits more extract leaves than expected, breaking the leaf/unmapped count. | The extract folds an INSTANCE to one leaf only when all its children are `slice_*`; otherwise it descends and emits the inner rectangles. | Expect a vector- or widget-built instance to descend; map its inner leaf by geometry, and place a widget component used as a bare plate as a flat CROP rectangle instead. | A `btn_close` instance descends and emits inner `Rectangle 5`; a `Popup` widget used as a bare `Bg_Popup` was placed as a flat CROP rectangle, not an instance (example) |
| P-7 | Every write silently no-ops; the file never changes. | The connector is on a View seat, and the seat can differ from the previous session. | Run `whoami` first in every session and abort writes on anything but a full seat. | The connector account flips between a Full and a View seat across sessions; a View seat fails every write with no error |
| P-8 | A 9-slice's middle band vanishes and the corners overlap. | The fixed top+bottom (or left+right) borders exceed the target dimension, leaving no room for the stretch band. | Assert `top + bottom < h` and `left + right < w` before instancing; drop to a single full-span cell on the failing axis. | nine-slice.md: "an axis with no uniform middle band is not sliceable — emit one full-span cell for that axis instead of three" |
| P-9 | Indexing a `use_figma` result throws or yields characters instead of fields. | Some transports return a large object as a JSON string. | `JSON.parse` defensively before indexing a large returned object. | Large `use_figma` returns arrive stringified under some transports; parse before use |
| P-10 | A style-bound text node's recovered ink height is short, so the gate over-subtracts a shadow the PSD layer never had. | The shared text style carries effects the individual PSD layer lacks; the gate reads effects from the style, not the layer. | Feed the gate the layer's own effects (plan 04's manifest recipe); build the node faithfully to the PSD and pin `position_only` when the style/layer effects diverge. | A shared `Body_50` recipe declares a DROP_SHADOW the PSD layer lacks, so the gate over-subtracted the bottom edge ~6.85px while the built node was correct (example) |
| P-11 | A glowing title's render bounds inflate symmetrically; the corner delta is large but the ink centre is exact. | Photoshop OuterGlow has no Figma equivalent; the substitute is a zero-offset `DROP_SHADOW`, which expands `absoluteRenderBounds` on all sides. | Substitute a zero-offset DROP_SHADOW with radius = glow size, expect symmetric inflation, and pin `ink_centre` since the centre stays exact. | `Hero_Title_115`: OuterGlow→DROP_SHADOW radius 11 offset 0 inflated bounds ~11px each side (corner dx −10.45 dy −10.65 dw +20.91 dh +21.30, centre 0/0) (example) |
| P-12 | A stroked or shadowed text node lands off its PSD position when placed by the manifest corner. | `absoluteRenderBounds` includes outside strokes and shadows, but manifest coordinates are glyph-ink only. | Ink box = render bounds − outside stroke on both axes; a drop shadow expands only the far edge and does not move the origin. | Memory trap 4: subtract the outside stroke from the target origin on both axes; drop shadow expands only the far edge |
| P-13 | Resizing an instance leaves its emitted child a fixed number of pixels too small. | The child rect is inset with fixed-pixel STRETCH margins, so the instance box grows but the margins do not. | Size the instance to `target + 2×margin` and offset by `−margin` so the child lands on the manifest box. | `Icon_Currency` variants hold their Icon rect inset 5px; sizing the instance to target+10 and offsetting −5 lands the child exactly (example) |
| P-14 | A faithful blurred text drop shadow overshoots the gate's ink box by ~2×radius. | The gate models effect expansion as `max(strokeWeight, shadow)` per edge, not stacked. | Build the shadow as radius 0 with offset `y = recipe_radius + recipe_offsetY − strokeWeight` so Figma's render bounds equal the gate's model. | `Text_CardAmount` with a faithful blurred shadow measured +15w/+8.5h; a radius-0 offset-adjusted shadow passed at ≤1.34px (example) |
| P-15 | A title's ink height is far short even though position is exact. | A PSD type-layer transform carries rotation, not just scale; the flat Figma text node cannot match the tilted glyph box. | Read the full transform matrix and apply the rotation to the text node, then re-place by ink box. | The `Stamina` title's transform is rotated −4.675° to follow its tilted plate; the flat node read dh −14.99 until rotated (example) |
| P-16 | Text built at the PSD's raw font size renders the wrong size. | The raw `psd-tools` `fontSize` ignores the type layer's transform scale. | Effective size = raw fontSize × transform scale; build the node at the effective size. | Memory: "the raw fontSize from psd-tools is NOT the rendered size; multiply by the transform's scale factor" |
| P-17 | Reproducing every reported effect produces wrong renders, especially strokes. | `psd-tools` reports disabled effects (`enabled=false`) alongside enabled ones. | Check `effect.enabled` and reproduce only the enabled effects. | Memory: "psd-tools reports all effects including disabled ones. Reproducing them (especially strokes with spread/choke) produces wrong renders" |
| P-18 | Colors come out wrong or clamped to white. | Plugin API color channels are 0–1, not 0–255. | Divide 8-bit channels by 255 before assigning a fill. | figma-use guidance: "Colors are 0–1 range (not 0–255): {r:1,g:0,b:0} = red" |
| P-19 | A `use_figma` call returns nothing useful, or a large build fails partway with no clue where. | `console.log` output is not returned, and a monolithic build hides which step broke. | `return` the values you need; break a build into small `use_figma` calls and validate after each. | figma-use guidance: "console.log() is NOT returned — use return"; "work incrementally in small steps ... validate after each step" |
| P-20 | A style or component created in the target file cannot be reused from another file. | An unpublished file's styles and components are local copies, not library-linked. | Confirm the file's publish state before planning to share anything across files; otherwise expect a copy. | Contracts: "unless the target file is published as a library, another file cannot reuse anything created there without copying it" |
| P-21 | A per-variant icon or boolean collapses to one value across the whole set. | After `combineAsVariants`, per-variant BOOLEAN / INSTANCE_SWAP properties merge into one set-level default. | When the value must follow the variant, give each variant its own nested instance with `isExposedInstance = true` instead of an INSTANCE_SWAP. | Contracts trap 2: an INSTANCE_SWAP for a per-variant icon forces every variant to the same icon |
| P-22 | Reading a node's field right after removing it throws "node does not exist". | `node.remove()` invalidates the JS handle immediately. | Capture every field you plan to report before calling `remove()`. | Contracts trap 3 / memory: "reading old.name after remove() throws 'The node with id X does not exist'" |
| P-23 | A Figma text node overflows visibly where the PSD box cropped it. | Figma text grows or overflows; it does not clip like a Photoshop paragraph box. | Wrap the text in a frame with `clipsContent = true` to reproduce the crop. | Contracts trap 5 / memory: "a PS text box crops overflow; a Figma text node grows or overflows visibly" |
| P-24 | A converted stroke inflates a text node's render bounds and pushes the label out of view. | Photoshop "choke" (%) and Figma "spread" (px) do not map. | Convert choke to an approximate pixel value via the stroke weight, or omit spread for thin strokes. | Setting `spread:100` inflated a price label's render bounds and made it invisible on six UpgradeRows (example) |
